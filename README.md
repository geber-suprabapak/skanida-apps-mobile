
# Skanida Apps Mobile
Aplikasi absensi siswa SMK Negeri 2 Kota Magelang



## Run Local Development Build

Clone the project

```bash
  git clone https://https://github.com/geber-suprabapak/skanida-apps-mobile
```

Go to the project directory

```bash
  cd skanida-apps-mobile
```

Install dependencies

```bash
  pnpm install
```

Prebuild for expo app

```bash
  npx expo prebuild
```

Run and build development build

```bash
    pnpm android
```
To only run the development server
```bash
    pnpm start
```
